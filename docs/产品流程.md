# 产品流程：开发 → 发布 → 运营（简化版）

2026-10-07。用户原话：「ok，那么先帮我调查一下产品流，包含开发、发布、运营。每个节点要做什么事。我不想搞很复杂，所以别把开公司找律师那种特别麻烦得东西都算进来」

范围：个人 side project、站点挂在美国、小规模真实用户、只收平台费和调用费。不含开公司、请律师。价格和条款多来自第三方整理，**签约前以各家官网为准**。

## 一、开发

| 节点 | 要做的事 | 完成标准 |
|---|---|---|
| 1. 引擎原型 | 节点执行（文本 / 图像 / 生成 / 结构 / 预览 / 后处理）、gpt-image-2.5 适配、模板存取、每次运行记录用量 | 用模板复现特调暗杀；能跑通"先生成人设图、再接到下游" |
| 2. 平台 MVP | 账号登录；额度账本（充值、扣费、余额不足拦截）；出图任务队列与执行器；节点画布网页；模板保存；内容审核；每次调用附匿名用户编号；用户可见的用量与花费 | 用户和一位真实用户各自登录、搭模板、出图、扣费，账目对得上 |
| 3. 上线前测试 | 正常流程跑通；故意的违规输入和提示注入要能拦住；扣费与 OpenAI 实际花费对账；出图失败时的退款或不扣费逻辑 | 一次完整对账无差额；违规样例全部被拦 |

内容审核与用户编号：OpenAI 的审核接口免费，可同时审文本和图片；官方建议每个用户传一个哈希过的唯一编号（safety identifier），出现滥用时只影响该用户；官方还建议提供人工处理的举报入口。

## 二、发布

| 节点 | 要做的事 | 说明 |
|---|---|---|
| 1. 域名与部署（美国区域） | 买域名；前端放 Cloudflare Pages（免费）；后端 API 与出图执行器放 Render（各约 $7/月）；数据库、登录、文件存储用 Supabase（免费起步，正式用 Pro 约 $25/月） | 固定成本约 $20–40/月（第三方价目估算）。Vercel 免费版禁止商用，且不适合常驻的 Python 服务 |
| 2. 收款 | 用"代理商户"（Merchant of Record）卖额度包 | 手续费约 4–5% ＋ 每笔 40–50 美分（第三方数据）。额度包建议不低于约 $10。个人所得税自己处理 |
| 3. 必要页面 | 定价页、服务条款、隐私政策、退款政策、举报 / 联系方式 | 用模板写，不请律师；条款里写明用户须遵守 OpenAI 使用政策 |
| 4. OpenAI 账户 | 在 OpenAI 后台设花费上限 | 上限是最后一道费用保险 |
| 5. 开放给用户 | 不做营销：发邀请链接或邀请码给已有用户；留一个反馈渠道 | — |

## 三、运营

| 频率 | 要做的事 |
|---|---|
| 每天（几分钟） | 看三个数：OpenAI 花费、卖出的额度、失败任务；处理举报和被拦截的请求 |
| 每周 | 对账（OpenAI 账单 ↔ 平台扣费 ↔ 代理商户收入）；查看用户反馈 |
| 每月 | 收代理商户的放款；更新依赖、检查备份 |
| 模型或价格变动时 | 用官方预设模板重跑一遍做回归；按新的 token 价格重算调用定价 |
| 出问题时 | 暂停出图队列；必要时暂停注册或某个用户；通过代理商户处理退款 |

定价公式（建议）：每次调用价格 ＝ 模型 token 成本 × 加成 ＋ 平台固定费。官方价目（2026-10-07 查）：gpt-image-2.5（sunburst / flare 同价）图像输出 $30 / 百万 token、图像输入 $8、文本输入 $5。2048×1024 high 每张约 1180 输出 token ≈ $0.037；带 3 张参考图约 $0.06。

## 四、收款方

用户原话：「我在美国。」

- 四家代理商户都支持美国个人收款（推导）：
  - **Polar**：自带按量计费、预付额度，最贴合"卖调用"；新账户 5% ＋ 50¢。
  - **Creem**：单笔费率最低（3.9% ＋ 40¢），也支持按量计费；放款手续费和代税覆盖范围说法不一致，注册前核对。
  - Paddle、Lemon Squeezy 也可以，但费率较高或按量计费较弱。
- Stripe 费率更低但不是代理商户，销售税要自己处理，不推荐。
- 开户通常要提交税务身份信息（如 W-9）。
